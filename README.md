# A Bit of String website

A plain HTML/CSS site, hosted for free on GitHub Pages. No build step and no server.

## Editing
- Text lives in `index.html`. Look for `EDIT:` comments.
- Colors and fonts are at the top of `styles.css`.
- Photos go in `images/`. The banner is `images/hero.jpg`.

To preview locally, just open `index.html` in a browser.

## Working together
1. Make a branch, edit, and open a pull request.
2. Someone else in the group reviews and merges it.
3. GitHub Pages republishes the site automatically within a minute or two.

Small fixes can also be made directly on github.com with the pencil (edit) button.
